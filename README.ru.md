# MagicNet

Рабочая среда прозрачной сети для Android с root, описанная воспроизводимыми программными рецептами.

[简体中文](README.md) · [English](README.en.md)

Название проекта остаётся MagicNet. Основной материал — рецепты в recipes/; исходный код является временным результатом генерации в игнорируемом generated/<implementation-name>/. Прежняя реализация сохранена в истории Git, коммит 96993ea5c851b8d51cc562c3ca0766a2ca571210, ; временный каталог android-reference удалён. Новый проект с суффиксом recipkg не создаётся.

Начните с [главного рецепта](recipes/magicnet/BUILD_PROMPT.md), [приёмки](recipes/magicnet/ACCEPTANCE.md), [источников](recipes/magicnet/PROVENANCE.md) и [измерений](recipes/magicnet/PERFORMANCE.md). Сохраняются возможности Android root/arm64, режимы tun|ebpf и языки; агент выбирает язык реализации и обновляет внешний вид без изменения рабочих сценариев.

recipkg check recipes/magicnet проверяет рецепты. pack создаёт Markdown-архив с зависимостями, build — полную инструкцию агенту. Это не подтверждает независимое восстановление или работу сети на устройстве. Реализация v1.8.0 доработана по новым рецептам на основе прежнего кода; это не независимое восстановление с нуля. Снимки исходников находятся в тегах этого же репозитория, main содержит рецепты. Проверки пакета и устройства учитываются отдельно в VERIFICATION.

Секреты остаются локальными. При публикации сохраняйте существующие topics и добавляйте recipkg. Лицензии сторонних компонентов действуют отдельно.

Для сборки выпуска клонируйте этот репозиторий с `--branch v1.8.0 --single-branch` в свободный `generated/magicnet-android/`, инициализируйте подмодули и следуйте инструкции тега. Нужны Rust/cargo-ndk, Android NDK, Go, Node/npm, Java/d8 и KAM; команда сборки — `kam build -j 2`. Версия рецепта: 0.2.0. [Установка и изменения](docs/releases/v1.8.0.md).
