# MagicNet

Рабочая среда прозрачной сети для Android с root, описанная воспроизводимыми программными рецептами.

[简体中文](README.md) · [English](README.en.md)

Название проекта остаётся MagicNet. Основной материал — рецепты в recipes/; исходный код является временным результатом генерации в игнорируемом generated/<implementation-name>/. Прежняя реализация сохранена в истории Git, коммит 96993ea5c851b8d51cc562c3ca0766a2ca571210, и локально в generated/android-reference/. Новый проект с суффиксом recipkg не создаётся.

Начните с [главного рецепта](recipes/magicnet/BUILD_PROMPT.md), [приёмки](recipes/magicnet/ACCEPTANCE.md), [источников](recipes/magicnet/PROVENANCE.md) и [измерений](recipes/magicnet/PERFORMANCE.md). Сохраняются возможности Android root/arm64, режимы tun|ebpf и языки; агент выбирает язык реализации и обновляет внешний вид без изменения рабочих сценариев.

recipkg check recipes/magicnet проверяет рецепты. pack создаёт Markdown-архив с зависимостями, build — полную инструкцию агенту. Это не подтверждает независимое восстановление или работу сети на устройстве. Миграция не публикует новую Android-версию; старые метаданные выпуска сохранены.

Секреты остаются локальными. При публикации сохраняйте существующие topics и добавляйте recipkg. Лицензии сторонних компонентов действуют отдельно.
