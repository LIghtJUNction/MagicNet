# MagicNet 界面设计

用内容之间的距离、字号和背景明度区分层级，让用户先看清状态与下一步操作。保留 MagicNet Fieldnotes 的矿白底、石墨正文、玉绿操作色和项目 Logo；视觉调整覆盖全部 14 页及公共控件。

## 空间与排版

页面留白按屏幕宽度递增，窄屏保留正文和操作空间，宽屏形成稳定的内容列。

| 视口宽度 | 页面左右留白 | 分区间距 | 常规容器内边距 |
| --- | --- | --- | --- |
| 320–374px | 16px | 24px | 20px |
| 375–639px | 20px | 24px | 20px |
| 640–899px | 28px | 32px | 24px |
| 900–1179px | 40px | 32px | 28px |
| 1180px 及以上 | 48px | 32px | 28px |

安全区超过表中值时以安全区为准。页面标题与主要内容沿用分区节奏；同一任务内部的标签、输入和帮助文字靠近排列。长列表保持连续的行布局，配置编辑器保留可用宽度。

排版使用系统无衬线字体，正文基准为 15px、行高 1.6，辅助文字 13px，通用标签 12px。页面标题随屏宽在 28–36px 内变化，概览状态标题为 32–48px；输入框至少 16px。代码、路径和机器标识使用等宽字体。所有尺寸使用统一 token，语言切换与放大文字后自然换行。

## 容器与边界

普通内容区默认无外边框，依靠留白与轻微背景差区分。公共卡片去除常驻描边和重阴影；卡内分组压平，以小标题、间距或一条必要分隔线组织。统计项使用透明背景，以数值、标签和间距组织阅读顺序。展开项与相邻内容共享层级，避免展开后再出现一层完整框。

边界保留在需要识别或操作的位置：表单输入、代码编辑器、交互焦点和危险提示。焦点轮廓清楚可见；高对比度及强制颜色模式恢复系统色边界。状态同时使用文字或形状表达，浅深主题均使用纯色页面底，通过背景层次和文字对比区分内容。

导航直接融入页面背景。视口从 900px 起显示桌面侧栏，去掉独立纸卡外壳，选中项使用淡玉绿背景与清晰文字；侧栏与分区导航高度至少 44px。顶部语言控件从 900px 起出现，引导、反馈与 GitHub 文案按钮从 1180px 起出现。移动导航保持稳定位置和可触达面积。主按钮强调当前任务，次要操作使用较轻的文字或浅底样式；常用按钮保持 48px，概览主操作为 56px 高、12px 圆角。

## 任务与状态层级

- 以“Android 网络仪表”为主张：一眼看清实际流量边界、当前模式、阻塞原因和下一步，而不是先摆四张统计卡。
- 将当前运行状态、用户意图、正在进行的事务和最近失败分出明确层级。未知使用文字/图形语义，不仅换灰色圆点。
- 密集的节点/应用/规则用可筛选行或列表；配置编辑器给正文空间；连接图只展示已证实链路，不造实时吞吐或世界地图。
- 正常、空、加载、错误、拒绝、pending、回滚和恢复中均有具体内容。弱网时保留足够上下文，成功提示不遮挡下一操作。
- 窄屏优先让任务正文可用，复杂诊断按需展开。320/360/390/430、横屏 844×390、桌面 1280×900 都检查；键盘弹出后输入和提交按钮不能被底栏挡住。
- 对话框限制焦点范围，Esc/取消后恢复焦点；支持跳到正文、语义标题、屏幕阅读器和减少动效。浅深主题的正文和主按钮对比度至少 4.5:1。
- 保留全部工作流、失败恢复与草稿。装饰动效轻量且可减少，不延迟核心状态或操作；字体使用本机资源。

## 路由编辑走查补充

Issue #413 的使用者并非只需要把现有节点切换入口改成中文：反馈明确要求无需手改 sing-box JSON，能按应用/域名指定出口，并创建自己的策略组/出口。路由工作区应让常用目标“应用、域名、出口”形成一条可预览流程；内置类型显示中文“代理/直连/拦截/自动测速”，保留并可搜索底层 tag。新建/编辑使用结构化字段与即时校验，密码等字段遮蔽；候选变更需展示影响的规则与目标，保存走已有配置事务并能恢复。不得用整段覆盖 route.rules/outbounds 的方式抹掉订阅和系统托管项。
