# MagicNet WebUI

交付普通 Android root 用户每天使用的控制界面。语言/框架自由，保留现有流程，重新设计视觉，不能降格成展示页。独立包不声明第二份控制面依赖；根包提供 control 的唯一 CLI/机器合同，集成时协商 capabilities。

阅读 DESIGN.md、SUBSCRIPTION_FLOW.md、ACCEPTANCE.md；产品保留 14 个页面：概览、流量路径、应用、节点与代理组、拦截规则、链式代理、订阅、Tailscale、配置文件、管理面板、健康检查、终端、工具、最近输出。日常导航直接提供概览、节点、订阅、应用，其余十页收进更多功能，沿用原分类帮助查找；全部页面仍可通过原地址和快速搜索直达，不重置历史或草稿。
节点与代理组有独立路由入口、可读的内置名称及原始 tag 搜索；名称翻译只改变显示，选择命令仍使用原始标识。用户提供的 constructor、__proto__、toString、hasOwnProperty 等名称必须当普通数据处理，刷新、测速和确认切换不能崩溃或串组。链式代理读取 node list 时，保留 [HK]、[US] 等方括号前缀及含选择、策略、Selector、URLTest、Fallback 的节点名；只剔除明确的兼容日志前缀，不能把所有以 [ 开头的行当成日志。选择与提交保留原始标签，候选集合及缓存回退遵守 control 合同。
节点页离开后重新进入，已加载过的代理组必须重新读取当前核心快照；首次可见只发起一次读取。离页或卸载后旧读取、旧测速及选择后的旧回读不能覆盖新快照；返回时旧读取仍在途，则等待它结束后只补一次新读取。保留搜索词和展开状态，仅取消最新快照中已失效或已选中的待确认节点，不因更新重置用户界面草稿。

Ctrl/Command+K 或 / 打开快速跳转，搜索不抢编辑器/输入框打字；Esc 关闭并恢复原焦点。自动引导等到服务与订阅读取成功，且确认服务停止、来源和缓存均为空；读取失败、已有来源/缓存或用户正在输入时不抢占界面。引导可取消、稍后手动恢复。首页按有效快照建议添加来源、更新订阅或“启动并检查现有配置”；建议置于概览顶部，首屏优先显示下一步及操作。cacheCount 只计远程原始订阅缓存，不表示有效节点或配置就绪；已有缓存，或 sourceMode=local 且 lastResult=success 时均可建议启动检查，后者允许 cacheCount=0。保留自定义配置的显式启动和内置节点直达。服务状态未知时主按钮只刷新状态。

## 视觉与空间

按 DESIGN.md 统一全部 14 页。浅色使用中性白或极浅灰底，深色使用近黑底；操作和选中以黑白及中性灰建立层级，语义色配合文字表达真实状态。独立设置任务使用单层浅底面板与轻描边，用对齐、标题和 32px 分区留白组织内容，长列表连续排列；共享圆角等级为 8px、12px、16px。嵌套内容保持平面，不叠加完整边框或阴影；输入框和次要按钮减轻视觉重量，编辑器、危险提示与焦点仍有清楚边界。

标题直接说内容，说明只补充操作所需的信息；去掉重复上标、宣传式副标和装饰性徽章。保留项目 Logo，点击返回概览；引导、反馈和 GitHub 通过更多菜单或快速跳转可达。删除模型署名和品牌连击彩蛋，独立流量路径页使用静态节点、连线与说明文字，不使用星形、发光、粒子或无限动效。示意图不证明已经接管流量或互联网连通，页头核心状态只表达已知进程状态；实时证据从概览运行详情与诊断查看。

正文基准 15px/1.6，辅助文字 13px、标签 12px，输入框至少 16px；常用按钮保持 48px 触控高度，导航至少 44px，概览主服务开关为 112px，服务名称与状态保持可读，Zashboard 保留清楚的任务入口。浅深主题、三种语言、窄屏和放大文字下，标题、导航、按钮自然换行，编辑区与主要操作保持可达。选中、禁用、错误与未知状态有清楚的文字或形状。

320px 窄屏下，流量路径节点名称、页头核心状态与说明文字须在各自内容宽度内完整换行；俄语长文案不得覆盖相邻内容或撑宽页面。允许路径区域随文字增高，保留说明文字与静态连线，不以裁切、隐藏或缩小字号掩盖溢出。

视觉调整复用既有组件和 schema=1 机器接口，保留 configured/effective、unknown/pending、草稿、危险确认和失败恢复语义；不新增机器写接口、设备持久化字段、网络资源或运行依赖。

## 手机端操作

手机使用底部 dock，入口为概览、节点、订阅、应用、更多。前四项每次点击都直接到对应页面，不要求先理解分区或再次点击已选项。更多从左侧抽屉打开其余十页，逐行展示图标、名称、说明与当前页；选择后沿用原路由历史和 KeepAlive 草稿。关闭、遮罩和 Escape 都能退出，焦点恢复到可见的更多按钮。桌面侧栏采用相同四个日常入口和可展开的更多功能；从地址、历史或快速跳转进入高级页时自动展开其所属导航，当前页不能藏在折叠区域内。

快速跳转同时提供至少 48px 的触控关闭按钮与桌面 Escape 提示。弹层高度与位置跟随可视视口，键盘弹出、平移或横屏时，搜索和关闭入口保持可达，结果在独立区域滚动。系统工具面板采用相同的可视范围约束，长内容滚动时仍能关闭。键盘打开时隐藏底栏，关闭后恢复；旋转、浏览器工具栏变化和缩放不能被误认为键盘操作。

手机应用页的搜索独占一行；匹配结果先展示 40 条，再以每次 40 条递增，并显示已展示数量与匹配总数。搜索词变化或清空后从首批开始；全选当前只作用于已展示的匹配项，保留逐项选择、明确的已选总数及既有批量确认流程。

手机终端的命令输入占完整一行，执行按钮另起一行，补全、历史和复制仍可触达。配置编辑器使用至少 16px 的等宽文字和统一 24px 行高，输入、高亮、行号与错误定位对齐；编辑区高度适配短视口，保留内部滚动、原生选择、撤销及内存草稿。

## 概览层级

概览依次组织服务状态与 112px 主服务开关、模式/延迟/RSS 摘要、日常任务链接。开关复用原启停动作、确认和忙碌规则；未知状态只读取状态。节点、订阅、应用、Zashboard 与检查网络保留明确入口；检查网络仍进入健康检查页。首次设置的下一步、异常与模块更新状态保持可见。延迟和 RSS 使用原字段、单位与未知值语义，不把局部延迟当成联网结论或把进程 RSS 当成整机内存。

运行详情与网络设置默认折叠。运行详情补充进程和综合服务检查，首屏摘要无需展开即可读；网络设置容纳 TUN/eBPF、热点、Wi-Fi 与服务管理，重启从服务管理进入。展开或收起只改变显示，不提交写操作或解除队列门控。流量路径说明保留在独立页面，概览不重复路径示意；关键错误、首次设置和更新进度不随详情隐藏。

## 本机 Zashboard

概览与管理面板提供 Zashboard 入口，宽屏顶栏同时提供快捷入口；各入口共用同一个打开流程，手机保留原快速跳转控件。管理面板优先展示打开按钮与真实校验状态，读取和校验作为常用操作；安装、下载和原始报告默认折叠，展开保留原操作和确认。未连接、核心停止、API 未就绪及本地资源缺失分别提示可执行的下一步，失败后可重试。

点击后读取本次有效的 schema-1 service.status，使用新响应中的 api.url、api.webui、api.ready 和 api.webui_ready。新 CLI 要求两个 ready 均为 true；false 或畸形字段拒绝。仅在旧 CLI 缺 webui_ready 时安静执行只读 webui verify，且只接受唯一 singbox_zashboard=ok，缺失、矛盾、非零退出或异常均拒绝。能力标记为 local_zashboard_readiness；缺省不能猜成 ready。

api.url 必须为有效 loopback HTTP origin；api.webui 必须同源且属于 /ui/ 路径，拒绝远端、userinfo、协议/端口错配和其他路径。保留通过检查地址的完整 #/setup 及连接参数，不能截掉 fragment。所有入口共享现有 busy/执行队列，重复点击不再投递第二次读取或导航，所有结束路径释放本次状态。失败不导航、不自动启动或下载；原始验证输出、私密配置与错误不进入共享输出，打开面板不改变联网结论。

## 控制与并发

概览和诊断页消费 `service.status.data.connectivity` 的缓存 Google 状态，区分内核/API readiness 与实际主目标结果。失败、过期和带旧失败的 pending 用明确 ⚠️、原因、预计重试和最近恢复动作；修复返回成功不能显示为联网成功。正常约 5 分钟检查，页面刷新不调用 tick、pingtest、订阅更新或自动修复。旧版缺字段显示 unknown。

诊断页提供“一键导出诊断包”，按 control/DIAGNOSTIC_CONTRACT.md 先协商 support.export，再执行一次写入。展示固定文件路径与大小，可复制路径；快速双击只启动一项任务，导出失败清除旧成功，原始错误/报告不进入共享输出。无原生 bridge 时禁用设备导出，不能模拟已生成文件。使用现有组件、串行桥和三种语言，不增加 npm 或运行时依赖。

通过管理器原生 bridge 执行受控 argv/私密 payload 文件，不把订阅/密码写 shell 字符串预览；无 native bridge 时明确只读预览，不模拟已连接设备。
先协商 JSON 能力，校验 schema/ok/command/data 后更新；不解析人类文本来替代已有 JSON。未知、坏 JSON、多 JSON、非零退出显示失败；失败刷新清除过期 live 指示为 unknown；保存错误保留编辑。
私密 sub/wifi/override inspector 安静读取，错误显示规范化代码，不捕获原始 payload。诊断使用脱敏 status。用户配置与实际 effective 分开展示。
串行执行直到 native exit/error，调用者超时不等于取消，不能提前释放执行槽。晚回调、切页、双提交和新操作的 ownership 检查防止旧结果覆盖。私密读取、载荷准备和后台投递同样拥有并清理自己的 busy/task；成功、失败和异常都收尾，旧操作不清理新操作的反馈。全量刷新失去 ownership 后停止排入剩余读取，设备后台任务仍按自己的证据继续对账。
原生输出收集上限 8,388,608 UTF-16 单元及 65,536 事件，两流合计，空事件计入；溢出清空丢弃且等待真实退出，明确 output-limit 错误，不把部分 JSON 当成功；终结路径移除 callback。
长后台任务通过设备 canonical/机器 status 恢复，关闭 WebUI 不丢失 module-update 工作。任务“接受”“完成”“需重启”和“已生效”分开。
订阅后台任务按真实、脱敏后保留的操作标识识别：URL 的 `webui payload apply-subscription`、本地文件的 `webui payload apply-subscription-source` 与旧 `sub apply-file` 都进入同次完成检查，不能只识别旧命令或依赖翻译后的按钮文案。当前任务仍 running、error 或 timeout 且无同次完成证据时，旧订阅 success 不能将其改成 done；私密载荷路径和内容仍不进入任务诊断。基线读取被新前台操作取代且尚未投递时，返回统一失败判定可识别的错误；调用者保留草稿，不显示已提交。

订阅读取单独保存内存状态 idle/loading/ready/error，仅最新有效快照进入 ready；已有 ready 的轮询可保留就绪，失败立即转 error。初始、读取失败、busy、queueDepth>0 或后台 running/timeout 时，统一禁用来源、导入、更新及设置写入，保留草稿及重新读取入口；UI 状态不进入设备 canonical。订阅全流程按 SUBSCRIPTION_FLOW.md 的 UI-SUB-001–UI-SUB-013 实现。多行输入、候选来源数、私密载荷、保存回读和同次激活结果必须对应同一来源集合；2–5 个来源不能在任何边界变成第一个来源。来源总数取已确认配置，不能用带用量的行数或节点总数反推。“检查来源”的 URL 语法、来源授权和域名解析结果均不表示下载、解析、激活或流量成功。URL 身份和合并/回滚行为服从根包提供的 runtime 订阅合同；需要同步的规范化修正必须同时覆盖所有入口，不能让界面和设备各用一套规则。

0.2.8 的 UI-SUB-013 接受 HTTP/HTTPS 语法，将来源授权交给设备后端。信任清单只由设备 CLI 明确管理；WebUI、安装向导和刷新不自动授权主机、CIDR 或代理。缺失、错配或已撤销授权时，设备拒绝应用并保留旧有效配置，界面保留全部草稿和可重试的失败反馈。语法有效、授权通过与实际下载/激活分别说明，不把某一层的成功替代其他层。

## 编辑、配置与敏感内容

配置草稿内存跨页保留；reload/import/sync-template 明确提示可取消的丢失风险；刷新/离开提示，草稿不存 localStorage。读取失败禁用保存；保存期间继续编辑不被旧成功结果覆盖；格式化保留可理解的光标/横向滚动。
覆写 preview/save/apply/reset 显示 pending/revision/conflict；管理字段不准从编辑器绕过。备份/恢复、节点/连接关闭、抓包、修复、停止、重启都有对应风险与确认。
network-access 先检查完整共享包名单，明确确认后写；只读检查不自动修复。Tailscale disable/resume/logout 区分，失败不报成功。

分流出口切换协议后，提交载荷只含当前协议支持的认证字段。username 仅用于 SOCKS/HTTP；VLESS 不携带隐藏的 password，继续保留 uuid/encryption；Trojan/Shadowsocks 保留当前可见的 password，既有 HTTP 凭据和 TLS 设置不丢失。

编辑已有 urltest 组的成员须保留原 url 和 interval。只有字段缺失时分别补默认 `https://www.gstatic.com/generate_204` 和 `3m`，成员编辑不能重置用户探测设置。

Tailscale 私密配置读取由首次可用、显式刷新或配置 revision 变化驱动。自身读取结束引起的 busy/disabled 解除不能触发无界重读；读取失败后保留明确的重试入口。

## 国际化与主题

WebUI zh-CN/en/ru，首次选浏览器首个受支持语言，否则 zh-CN；手动选择存在 magicnet.webui.locale，存储失败不能阻塞 UI；HTML lang 同步。
语言切换不 remount、不丢草稿；仅 UI 解释翻译，命令/配置/用户数据/日志不翻译。翻译完整句子与命名占位符相同；历史操作保留发生时语言，内嵌第三方面板自管语言。
提供 light/dark/system 及减少动效。无 RTL 需求；locale 日期/数字/时区的更深规范尚未确认，不能凭空新增格式承诺。
