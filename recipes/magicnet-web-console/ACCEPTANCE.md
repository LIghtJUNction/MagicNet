# UI 验收

本轮 M82 按 UI-MOBILE-001–004 覆盖 360/390/430px 手机界面。历史条目中的桌面尺寸保留兼容背景；本轮不追加桌面改造、截图或通过结论。

UI-CON-01–04：概览/诊断的⚠️、退避、主目标恢复与内核ready区分；失败刷新清除旧成功、旧模块字段缺失为unknown；只读刷新不得执行tick/订阅更新；诊断按钮能力协商、快速双击单任务、错误后清除旧文件确认、路径/字节校验及私密错误不泄漏。无bridge禁用，三语文案齐全。执行生产事件函数的原生桥夹具与真实浏览器/Android WebView结果分开，不因无浏览器权限而把函数模拟写成视觉验收。

1. 在全部 14 页按 360/390/430px 手机宽度检查 light/dark 与 zh-CN/en/ru；可见文字、层级与主要操作完整，主页面无横向溢出，节点/编辑器内部滚动保持可用。逐页覆盖含 proxies，不漏工具、输出或流量路径；截图范围按 UI-MOBILE-001 记录。
2. 无 native bridge 明确预览，连接断开/状态错 JSON/请求失败后旧绿色 live 状态清为 unknown；不得显示虚构成功。
3. Ctrl/Command+K、/、Esc、键盘导航、modal trap、取消、嵌套工具进入 palette/onboarding 后恢复原可见焦点；编辑器里 / 不抢输入。

6. URL/SSID/BSSID/private inspector canary 只在对应编辑器出现，不进 reactive stdout、通用诊断、错误对话框或 issue 正文。
7. module-update accepted 后关闭重进，从设备状态恢复；stage 成功只显示 reboot_required。相同请求幂等，失败保留 retry/恢复提示，不自动重启。

20. 手机底栏的概览、节点、订阅、应用每次点击均直达对应页面；更多一次点击从左侧抽屉打开其余十页，不要求重复点击当前项。桌面四项直达与更多功能提供相同页面集合；逐项核对全部 14 页不重复、不遗漏。更多面板列出图标、名称、说明和当前页；高级页的深链接、历史返回与快速跳转自动揭示桌面导航项。原地址、历史与 KeepAlive 草稿保持，关闭、遮罩及 Escape 恢复可见触发按钮的焦点。
21. 快速跳转提供至少 48px 的可触控关闭按钮，桌面保留 Escape 提示。以 320×740、390×844 和 844×390 检查打开、搜索、清空、结果滚动、选择和关闭；键盘导致可视视口缩小或偏移时，搜索与关闭控件仍可达。系统工具长内容滚动后仍有可达的标题和关闭入口。
22. 编辑输入时打开和关闭软键盘，底栏分别隐藏和恢复，当前页面、输入内容及焦点不被重建；旋转、浏览器工具栏变化和页面缩放不会误触发导航或丢失草稿。分别记录浏览器视口验证与 Android WebView 软键盘实测范围。
23. 用超过 120 个应用的固定夹具检查初次 40 条、继续 80 条及最后不足 40 条的分页展示；显示已展示数量与匹配总数，全部结果均可到达。改变或清空搜索词后恢复首批；全选当前只选已展示的匹配项，隐藏及尚未加载项不被暗中选入，已选总数和批量确认范围准确。手机搜索独占一行，长应用名及包名不会挤出页面。
24. 手机终端的命令输入完整占一行，执行按钮位于独立一行；输入较长命令后仍可使用补全、历史、执行及复制。检查 320px 宽度、横屏短视口与键盘打开场景，保留原生输入、焦点导航和既有执行确认行为。
25. 手机配置编辑器的等宽文字为 16px、行高为 24px；首行、中部和错误行在输入、高亮、行号三层对齐。短视口内编辑区可滚动、操作可达；字体放大、横向滚动、错误定位、选中文本和撤销不会错位或丢失草稿。

26. 全量刷新期间切换到配置页私密读取、载荷准备或后台投递；分别完成、失败及再发起新操作。旧刷新不继续排剩余读取，当前操作结束后 busy/task 清理；旧结果不覆盖新反馈，后台任务仍保留自己的对账与写锁。订阅基线读取被取代且未投递时返回 execFailed 可识别错误，调用者不显示已提交、不丢草稿。
27. 初始空默认值、读取失败、已有 ready 后轮询失败及旧失败晚到；来源/导入/更新/UA/过滤/周期写入统一要求 ready、busy=false、queueDepth=0 且后台任务不为 running/timeout；分别注入这些阻塞并确认不投递写入，重新读取始终可达。失败不泄露私密内容、不丢草稿，恢复读取不覆盖用户输入。
28. 服务/订阅读取未知、确认空、只有远程来源、已有原始缓存、本地上次成功但 cacheCount=0 及自定义配置分别打开概览。下一步对应读取/导入/更新/启动检查；有建议时置于概览顶部，在 320×740 首屏完整显示建议与操作。原始缓存不显示成有效节点数或配置就绪，本地成功无远程缓存仍建议启动检查；未知主按钮只读，内置节点可直达，自定义配置仍能显式启动。自动引导只在确认停止且来源/缓存均空时出现；切页、输入或已打开弹层后不抢焦点。

29. Logo 点击返回概览；界面与键盘操作中没有模型署名、品牌连击彩蛋或宣传式副标。页面和分区标题不叠放同义上标与描述，计数和普通说明不堆成徽章；低频顶栏入口移至更多菜单后仍可用。检查顶栏、快速跳转和分区面板的触控与焦点恢复。
30. 独立流量路径页使用静态说明节点、连线与文字，没有星形、光晕、粒子、无限呼吸或流动虚线；示意图不作为已接管流量或互联网连通的证据。分别注入 unknown、stopped、ready 与失败快照，核对概览状态、运行详情、诊断及路径页头的核心状态与各自机器事实一致，不要求静态路径节点承载实时状态。浅深主题正文、辅助文字和主按钮对比度至少 4.5:1，语义色只标识真实状态。

31. 在 320×740 的俄语流量路径页中，检查路径节点名称、页头核心状态与说明文字的实际边界均处于各自内容区域内；长文案完整换行，相邻内容不覆盖，页面无横向溢出。对照中文、英文及浅深主题，保留说明文字与静态连线；不以隐藏溢出、删字或缩小字号通过验收。概览不重复显示该示意图，更多与快速跳转仍能进入完整说明页；实时证据从概览运行详情与诊断查看。

32. 在真实分流编辑组件中先填写 HTTP/SOCKS username/password，再切换为 VLESS、Trojan 或 Shadowsocks 并预览载荷。username 仅随 SOCKS/HTTP 提交；VLESS 不提交隐藏 password 且 uuid/encryption 完整，Trojan/Shadowsocks 保留可见 password。对照 HTTP 凭据与 TLS 编辑，确认当前协议支持的字段不丢失。
33. 修改带自定义 url/interval 的 urltest 组成员，预览和保存均保留原参数；字段分别缺失时仅补对应默认值，新建组使用默认 `https://www.gstatic.com/generate_204` 与 `3m`。组件载荷回归与浏览器交互结果分别记录。

34. 首次打开概览时服务状态与 112px 开关、模式/延迟/RSS 摘要、日常任务链接形成三个清楚层次；运行详情与网络设置仍折叠。摘要采用原字段和单位，缺失保持未知；启停复用原确认和门控，检查网络只导航至健康检查页。展开后进程、综合服务检查、TUN/eBPF、热点、Wi-Fi、服务管理及重启完整可用；展开、收起不投递设备写入、不改变队列或草稿。
35. 在详情收起时注入未知、离线、过期失败、恢复中、初次未配置与更新已暂存状态。关键警告、下一步和更新进度仍可见，unknown 不显示成功，修复动作成功不替代联网证据。切换主题、三语和 320px/横屏/桌面尺寸，四个日常入口与更多均可辨认，路径页和高级设置不丢功能；记录实际截图和浏览器范围。

36. 从概览、管理面板和宽屏顶栏打开 Zashboard；旧快照 ready 但点击时新 API/资源失败则不导航，新快照通过才打开同源 loopback /ui/ 并保留 #/setup 参数。拒绝坏 envelope、错误 command、非零退出、远端/userinfo/跨端口/其他路径；原始输出与私密 canary 不进入共享日志，失败可重试。
37. 新字段 true/false 直接采用；只有 webui_ready 缺省才只读 webui verify。仅唯一 singbox_zashboard=ok 放行，missing、重复矛盾、缺标记、失败及异常均拒绝。快速双击与跨入口共享 busy/队列，只投递一条流程，结束后可重试；不自动启停、安装或下载，不将面板就绪当联网。
38. 三语、浅深主题、320px/横屏/桌面检查概览主次操作和管理面板：112px 服务开关、状态摘要和任务链接可辨，节点/订阅/应用/Zashboard/检查网络可达；维护区默认折叠，展开后原功能完整。未连接、停止、API 失败和资源缺失提示清楚且不溢出，订阅筛选文案明确表示“排除词”，“清空”仅修改草稿并需显式保存；导入/跳过计数来自现有订阅状态。保存实际截图，桥接夹具/浏览器/Android WebView 分别记录。

## 0.2.8 受信任来源

用同一 HTTP/NAS URL，在缺失授权、精确授权、错端口、撤销授权四种状态下检查和保存；前端语法结果一致，后端仅允许准确授权。成功仍须通过既有任务退出与同次结果回读确认，拒绝保留草稿与旧有效配置。安装向导执行同一策略，界面不提供自动信任或代理旁路。复核默认 HTTP 80/HTTPS 443 规范化及 path/query 字节保真，canary 不进入共享输出或 Issue。

以上条目为验收要求。原实现、后续视觉迭代与独立重建的实际执行结果分别记录在根包 VERIFICATION.md。
