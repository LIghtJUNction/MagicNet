# 集成验收

以下是重建实现未来必须运行的验收，不是本次迁移已经通过的产品测试。合成夹具不使用真实订阅/SSID/密钥。每个场景记录源码版本、设备/环境、输入、退出码、输出、文件前后摘要和剩余资源；失败必须保留。

| ID | 输入与操作 | 可观察预期 |
| --- | --- | --- |
| M01 | 新 root 设备安装 full ZIP，重启，打开引导，提供合法合成测试订阅 | 全组件校验通过；候选激活；health 与 transparent 状态各层有证据；不占 Android VPN slot |
| M02 | 对相同有效配置重复 apply；只修改无关文件 | 有效配置/规则未变化不重启核心，不切断已有长连接 |
| M03 | tun→ebpf，注入启动/attachment/提交失败；再成功切换 | 失败逐字节恢复旧配置、模式和已拥有资源；不把 tun 检查套到 ebpf；成功后两数据面互斥 |
| M04 | URL→本地→URL；每阶段下载、解析、校验、替换故障并中断 | 旧有效来源/配置/selector 保留，恢复日志可重放，未提交用量不展示成已生效 |
| M05 | 多用户安装/卸载同包；共享 UID；分别选择 proxy/direct/bypass | 对应真实 UID 重新解析，bypass 同时绕过 DNS，其他应用/系统规则不受牵连 |
| M06 | Wi-Fi 名单命中/未命中、禁用；热点接口晚出现/消失 | mode 语义准确，未知不当作未命中；热点 pending 可见，关闭恢复先前 offload 与仅自有路由 |
| M07 | 覆写对象/数组/null；两个客户端同时编辑；失败激活与外部改写 | 合并/替换/删除准确；stale revision 冲突；无效写零副作用；回滚不覆盖第三方改动；保存≠运行 |
| M08 | WebUI 操作超时后立刻第二次写，关闭再重开 | 原生命令退出前串行槽仍被持有；长任务由设备文件恢复；旧响应不能覆盖新状态 |
| M09 | 未认证 MCP、错误类型/未知字段、私密文件及 symlink 别名、diagnose 尾随参数 | 独立拒绝；无命令执行与敏感值泄漏；资源只返回脱敏 schema-1 |
| M10 | 手动停止核心后保存配置、暂停/恢复 Tailscale；共享 CGNAT 非 Tailnet 目的地 | 不意外启动核心；不强迫整个 CGNAT 走 Tailnet；登出只删模块自有身份 |
| M11 | network-access 检查、缺少确认、stale 候选、成功 repair、第三方改策略、rollback | 检查零写入；只改审阅的身份；有界私密 journal；冲突拒绝；配置 readback 不能宣称 Play 可用 |
| M12 | 替换组件 ZIP 字节、路径穿越、缺组件、网络中断、移动文件时强杀 | 校验前不激活；拒绝不安全包；旧配置保留；重试先恢复；不删除无法证明归属的 staging |
| M13 | 更新同 ID 同意图、同 ID 不同意图、并发请求、成功 staging 后未重启 | 幂等/冲突/busy 分明；旧生效版本保持；仅显示 reboot_required；不自动重启 |
| M14 | 320/360/390/430、横屏、桌面；zh-CN/en/ru；键盘/屏幕阅读器/reduced motion | 14 页可达，含节点与代理组独立入口；关键状态和错误可读；草稿、焦点、确认、键盘避让、布局无阻挡；无虚构实时数据 |
| M15 | TLS/DNS/真实 App UID 流量、前后台与网络切换、TUN/eBPF、热点客户端 | 正确出口、规则与 DNS 边界有真实包/应用证据，不能仅凭配置、curl root 或进程证明 |
| M16 | 故意植入凭据的合成配置，导出 support/backup、状态与发布包 | 公共结果脱敏；备份按私密导出合同处理；发布包无 .env、运行状态、密钥和私密日志 |
| M17 | 依照 PERFORMANCE.md 在相同 workload 复测 | 正确性先通过；报告样本、median/range、失败数、资源边界；没有未经确认的目标数字 |
| M18 | 新手按应用名称和域名建立自定义分流，选择或创建可读策略组/出口 | 中文名称与原始 tag 均可搜索；结构化表单预览影响；校验失败零写入；不覆盖订阅托管项；成功可撤销 |
| M19 | hotspot reconcile 持锁期间发起 service start/stop/restart，含核心已运行的 no-op | 周期任务争锁失败时无副作用跳过；交互动作有界等待并报告 busy/pending，不把锁冲突伪装为核心故障或成功 |
| M20 | 热点拓扑变化、长时间配置应用、WebUI 超时后连续操作 | 显示设备侧阶段/耗时/结果；只阻塞冲突写操作；超时不释放仍运行的任务所有权；完成后刷新新证据而非旧状态 |
| M21 | 安装器迁移清单新增路径、显式排除项、备份/恢复/复制故障 | 迁移来源单一；模板重建例外可审阅；状态丢失风险在退出码和日志中可见，失败留有恢复证据 |
| M22 | 连续五轮启动/优雅停止；注入 stop 超时、PID/归属未知、资源清理失败 | 只清理模块拥有的 tun/eBPF 资源；升级终止前等待清理证据；停止后原生网络恢复；任何一项 unknown/stale 时不报完整成功 |
| M23 | TUN/eBPF 热点下游做 IPv4、IPv6 TCP/UDP 请求与返回路径检查 | route readiness 与真实回程证据分开；无全局 IPv6 的客户端标记未覆盖；TUN/eBPF 状态判据各自正确，不复活 TProxy/Redirect |
| M24 | 真实 Google Play、GMS、GSF 的 DNS 与应用请求，含至少两种 OEM 策略环境 | health、root curl 和 API readback 均不能替代应用成功；分别识别代理出口、DNS 与 per-UID 策略；不做无证据的全局 direct 绕过 |
| M25 | Tailscale 发现、TSMP/ICMP 与实际 Tailnet 应用访问 | 三层结果分别记录；DISCO 成功但业务失败不能标成在线可用；比较核心版本/模式并保留未知根因 |
| M26 | 同设备重复冷/热启动、空闲扫描和不少于 600 秒公网稳定性观察 | 固定 artifact、配置、观察器开销与时间口径；记录阶段耗时、exec 次数、重复扫描、失败和资源；未定义预算继续标未知 |
| M27 | 活动 config 为空/损坏、last-known-good 缺失/损坏、事务中断 | 仅使用独立校验通过的备份恢复；无可用备份时拒绝激活并保留 journal；可安全重试且不覆盖用户意图 |
| M28 | 订阅下载超时、解析失败、核心启动失败及重试/取消 | 阶段和规范错误可区分；未知原因不臆测；私密 URL/响应不进入公共状态；重试不产生重复 owner |
| M29 | 在锁定 sing-box 核心上对比 mixed 与 Go/default TUN stack | 热点回程、DNS、策略、IPv4/IPv6、长连接和资源指标全过后才可提议换默认；stack 选择不改变 tun|ebpf 模式语义 |

M18–M29 来自 [FEEDBACK.md](FEEDBACK.md) 的 Issue 反馈。它们属于未来重建的验收要求。本次迁移仅运行配方检查、归档/提示词校验，以及 PERFORMANCE.md 明确记录的原实现基线；M01–M29 的独立重建验收全部未运行。旧设备只读走查因安装版本过旧且随后断连而受阻，不能标为通过。
