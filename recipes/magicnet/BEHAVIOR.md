# 用户行为与端到端合同

## 首次成功

用户通过 root 管理器安装模块并重启；系统 Private DNS 应关闭。首次进入 WebUI 先读取服务与订阅，仅在确认服务停止、来源与缓存均为空时自动引导，可取消并稍后继续。用户输入一到五个远程来源或导入本地内容；远程默认只允许公网 HTTPS，可信本地来源须先按 SUB-016 私下授权精确 origin 与地址范围。服务下载/解析候选、结构化合并、校验后才激活。
成功必须同时有受控 sing-box 进程、可用管理 API 与当前数据面证据；未配置、空节点、拒绝的格式、失败下载有可理解的结果，不能显示已代理。

## 日常工作

1. 日常导航直接提供概览、节点、订阅、应用，更多保留其余十页；原地址、历史与快速跳转继续可用。概览默认展示服务状态、启动或停止、刷新、检查网络及重要异常；进程、综合服务检查、实际模式与 RSS 放在运行详情，模式切换、热点、Wi-Fi 与重启放在网络设置，两组默认折叠，配置意图与实际值仍分开。独立流量路径页是静态说明，示意图不证明联网；实时证据从概览运行详情与诊断查看。按确认的来源/缓存在概览顶部给出导入、更新或启动检查建议，首屏优先显示。远程原始缓存不表示有效节点或配置就绪；本地来源上次成功且无远程缓存也建议启动检查，自定义配置仍可显式启动。状态未知时主按钮只读刷新，原确认和任务门控保留。
2. 订阅支持 URL/本地来源原子切换、刷新、用量与到期信息、更新周期 off/12/24/48/72 小时、User-Agent、过滤规则。失败保留当前有效来源、配置和选择。来源事务不等同于独立设置的 UA/过滤/周期保存事务，不谎称后续失败自动撤销已保存设置。
   一至五个来源必须完整传入、逐源转换和整批提交；同名不同节点不丢，真正重复有明确归属；统一 URL 身份，失败候选数与当前已保存数分开。具体规则与 UI/公共状态按 SUB、UI-SUB、C-SUB 合同。HTTP 输入只通过语法检查，不会自动取得访问 NAS、CGNAT 或 Tailnet 的权限；授权失败保留草稿、当前来源与配置。VLESS Encryption 在已支持入口完整保留，未支持组合显式拒绝，不能剥字段后宣称成功。
3. 节点列表、当前选择、延迟测试、自动 urltest、业务独立 selector、链式代理的前置节点/出口与 manual/auto；选择持久化，更新后消失的节点重建成合法候选。没有合格出口时 fail-closed。
4. 应用支持 proxy/direct/bypass、名单模式、搜索/批量设置；覆盖 Android 多用户、重装、共享 UID。proxy 强制代理；direct 经数据面走 direct；bypass 同时离开数据面与 MagicNet DNS 捕获。
   用户可按应用名称或域名配置出口，并通过结构化界面维护自定义具名策略组/出口；保存前预览范围，增量合并时保留订阅和系统托管规则。托管应用、自定义域名、广告策略按固定顺序插在保护及元数据准备动作之后，保留原有规则次序；显式业务 route 不会被提升为保护规则。
5. Wi-Fi 名单支持 SSID/BSSID、blacklist/whitelist、启停和 3–300 秒间隔。blacklist 命中用 direct，其余 rule；whitelist 命中用 rule，其余 direct；disable 恢复 rule。
6. 热点 direct/proxy 不创建热点，不替代 OEM DHCP/NAT；下游消失是 pending。代理时持有的 offload 设置、路由和 TC 必须在停用/卸载时准确释放或恢复。核心退出而监督循环仍运行时，按 CON-006 在既有配置锁内重新确认后清理自有 DNS/热点资源；不复活已停止服务，不把清理结果等同于网络恢复，未知身份与其他所有者的规则保留。
7. JSON 编辑器支持读取、格式化、校验并保存、模板仓库选择和同步；未保存草稿跨页面保留，刷新可丢失，离开前提示，不存浏览器持久存储。
8. 持久覆写使用 JSON Merge Patch；保存草稿与激活分开，支持 preview、expected_revision、reset、冲突和回滚。受控入站/API/热点字段不可篡改。
9. 网络设置 IPv6 策略、MTU、UDP 超时、DNS profile、捕获端口和 TUN CIDR；读接口分 configured/effective。默认双栈 prefer_ipv4、1400、5m、1053、172.19.0.1/30。托管默认配置中的 `.local` 与链路本地反向区域通过 mDNS 查询当前本地链路，不发送到公共 DNS；本地无响应时报告失败，home.arpa 与 .lan 仍沿用既有策略。端口/网段冲突必须诊断。
10. 应用网络限制恢复只操作用户审阅并确认的候选，展示所有共享身份的包；先检查，后显式 repair/reapply/rollback，不做开机或安装自动解禁。
11. 广告/域名规则、allow 例外、社区规则开关、路由域名 direct/proxy/block/warp、WARP WireGuard 导入和 rule/global 模式继续可用。
12. userspace Tailscale 不创建第二个 TUN；保留登录、暂停、恢复、显式本地登出和失败待清理状态。停用不等于登出，不删除自定义状态目录或云端账号。WebUI 私密配置读取由首次可用、显式刷新或配置 revision 变化驱动；自身读取解除 busy 不触发无界重读，失败保留重试入口。
13. 内嵌节点面板、代理组/连接/统计、关闭单连接/匹配连接/全部连接可用；流量和原始 API 数据按私密边界处理。
14. 健康、拓扑、DNS 测试、网络预检、日志、脱敏支持包、加密备份/恢复、终端命令保留；HTTP delay 不写成 ICMP ping。
15. eCapture tls/gotls/nspr/pcap 为用户主动发起的有界诊断；不安装 CA，不保证任意浏览器 TLS 明文；文件非空、捕获成功与进程启动分开。
16. MCP 默认关闭，独立 secret 认证；机器状态与 UI 一致，显式私密工具与自动脱敏资源分开。
17. 官方模块更新可检查、安装和恢复后台状态；成功 staging 只显示需重启，不能冒充已生效，也不自动重启。

## 操作菜单

终端编号+回车，空输入退出；管理器音量减选择、音量加确认。默认只读诊断；启动和停止独立。断网可能性的停止/订阅更新再次确认且默认取消。MAGICNET_NONINTERACTIVE=1 只显示状态，不阻塞等输入；失败退出码不能被刷新覆盖。

## 不包含的服务

MagicNet 不提供订阅、节点、出口账号、Android root、本地热点控制器、系统级 Tailscale 账号管理或通用远程 shell 服务。规则数据更新由新构建携带；普通订阅刷新不会偷偷改变上游分类数据。

## 当前代理的联网确认与恢复

联网状态分别说明“当前所选代理能否完成双站点 HTTPS 204”和“mixed 数据面能否完成请求”，避免测试域名走其他路由组后掩盖当前节点失效。概览的“检查网络”打开诊断页，普通刷新读取缓存；需要新严格结果时显式运行 cli connectivity check。诊断中的既有 ping 工具不等于当前代理的严格双 HTTPS 204。节点切换后及时复验，不让旧退避结果代表新节点。

满足自动恢复证据和冷却条件时，最多检查三个同组已有真实代理。候选验证后切换并持久保存，运行态复验失败则补偿旧选择；保存失败直接报错，外部新选择不被回滚覆盖。人工检查只探测，停止意图、订阅刷新间隔和 TUN 恢复次数保持，不能通过反复点击检查重新获得恢复额度。
