# MagicNet Constellation

面向 Android root 管理器 WebView。视觉直接取自 `icon.png`：奶油色纸面、墨线、陶土橙底和虚线连成的星座。虚线星座是唯一的装饰母题，其余保持安静，让真实运行状态成为页面主角。

| --- | --- | --- |
| 背景 | `#F7F2E8` | `#14120F` |
| 卡面 | `#FFFCF6` | `#1D1A16` |

| 错误 | `#AD2E2A` | `#F2988A` |

- 标题与概览状态使用系统衬线字体栈（`--font-serif`），正文使用系统无衬线；等宽字体只用于代码、路径、PID 与模式标签。不下载外部字体。
- 概览状态 36–56px；页面标题 28–38px；正文 14–16px；输入框至少 16px。
- 深色主题背景只有一层静态、稀疏的星点（`--mn-sky-field`），从不动画；高对比度与强制颜色模式下移除。
- 绿色、黄色和红色只表达真实状态。陶土橙是品牌主色，不能充当成功色；危险操作使用独立的红色。

## 空间与组件

- 手机两侧留白 20px，内容单列；分区之间 14–28px。
- `Card` 是有细边框的纸面（圆角 20px，极浅投影）；嵌套卡片改为下沉面，不叠加投影。
- `details.mn-disclosure` 与卡片同形，展开内容自动继承内边距。
- 按钮最小触控高度 48px，概览主操作 58px 胶囊形；加载中保留名称。
- 状态分区标签使用分段胶囊轨道；选中项是凸起的纸片，强制颜色下改为 Highlight 轮廓。

## 导航

- 顶部：Logo、字标、快速跳转、主题、刷新、更多。桌面额外显示语言、引导、反馈与 GitHub。
- **快速跳转**（`Ctrl/⌘ + K` 或 `/`）：搜索全部 13 个页面和安全的面板操作（刷新、外观、引导、反馈、外链）。不提供任何会改动设备的命令；中文原文与当前语言译文都可匹配。组合框语义、方向键选择、Enter 执行、Escape 关闭并恢复焦点。
- 手机底部为悬浮胶囊坞，四项：运行、路由、订阅、诊断；选中项为墨色实底。键盘展开时隐藏。
- 桌面侧栏为纸面卡片：每页带图标，选中项陶土色底与左侧刻度；底部是实时状态卡（服务状态、模式、内存），点击回到概览。
- 保留地址栏路由、返回历史、延迟加载和 KeepAlive 草稿。

## Signature Mechanism: Live Constellation Path

概览英雄区把流量路径画成四颗星：设备 → 数据面（TUN `magicnet0` / eBPF）→ sing-box → 出口。

- 每颗星只由一个机器接口事实点亮：数据面看 `transparent.dataplane_ready`，核心看 `process_state`，出口看 `readiness.overall`。
- 两端都已证实时，连线才是流动的陶土虚线；任一端停止为稀疏点线；未知为静态灰色虚线。未知永远不画成接管。
- 出口星点亮只代表 sing-box 已就绪并按规则分流，说明文字明确提示实际联网需在诊断中确认。
- 减少动效时虚线停止流动；强制颜色下连线与星点改用系统色。

## Precision Editor Rail

保留原生 textarea 的输入、撤销、选择和键盘行为。行号、错误定位和虚拟化高亮必须对齐，不把编辑器做成装饰性终端。

## 页面层级

1. 概览：真实服务状态、启动/停止、节点面板、重启。
2. 代理模式：显式 TUN / eBPF 选择；运行细节按需展开。
3. 热点开关；Wi-Fi 策略和维护操作收进展开项。
4. 订阅：已配置时展示来源和供应商用量，管理入口展开地址编辑；首次配置时地址和保存优先。敏感信息脱敏，记录、过滤、标识和自动更新次之。
   用量、配额和到期时间必须来自供应商响应，不能冒充设备流量或本地更新记录。
5. 应用：名单与搜索优先；保留策略路径预览、修改前后对比及重新解析 UID。包名添加、报告和影响分析次之。
6. 配置：编辑区优先；仓库与结构分析可展开。错误行和未保存状态保持可见。

## Components

### 终端

- 延续 Constellation 的浅/深主题语义色、细边框和圆角；命令与输出使用等宽字体，不另设固定黑底配色。「就绪」使用中性文字和圆点，只表示可以输入命令；完成与失败另以文字和语义色标明。
- 输出区独立滚动，输入区位于其下方，不随输出滚走。手机上降低输出区高度，快捷命令换行；长命令与输出在区域内折行。
- 输入使用可见标签与 16px 字体；执行、复制、补全和历史操作保留至少 48px 触控目标与可见焦点。Tab 仅在确有补全变化时接管；空输入、无可用补全及 Shift+Tab 保留正常焦点导航，键盘用户能离开输入区。
- 当前页历史与输出仅留在内存，离开后清除；「清屏」与「清空历史」保持独立。等待输出使用文字提示，减少动效模式下停止提示点动画。

### 配置覆写编辑器

- 「完整配置」与「配置覆写」显式切换，以按钮样式和按下状态共同表示选择；完整配置的加载、保存与更多操作只在对应视图出现。覆写复用 Precision Editor Rail，视图切换保留内存草稿。
- 主操作为「保存并应用」，其次是「校验预览」和「仅保存」；复制草稿、重新读取与重置放在次级操作行。窄屏按钮自然换行，保留既有 48px 触控高度。
- 「未保存」「等待应用」「已保存」使用明确文字，保存不能冒充应用成功。校验结果与失败提示紧邻操作区；操作期间禁用编辑与重复提交。
- 有未保存草稿时，重新读取先展示「保留草稿」与「放弃草稿并重新读取」。版本冲突保留当前编辑内容，并提示先复制草稿；不静默覆盖。草稿内容按私密配置处理，不写入通用操作日志或浏览器持久存储。
- 重置只针对覆写，保留订阅和其他设置。页面沿用现有主题、排版与代码编辑器，无新增产品位图资产。

## 安全与可访问性

- `tun|ebpf` 必须显式选择，不能用视觉状态提前宣布切换成功；eBPF 不要求 `magicnet0`。
- 不把服务运行等同于互联网连通，不把未知数据画成成功。
- 高风险操作需要说明后果并确认；弹层限制焦点、支持 Escape，取消后恢复触发点焦点。
- 保留失败原因、恢复操作、隐私提示和草稿；删除重复教程与实现自述。
- 选中、错误和运行状态同时有文字或形状，不仅依赖颜色。
- 支持浅/深主题、放大文字、强制颜色及减少动效。
