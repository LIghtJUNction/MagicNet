# 运行时边界

## 单一写入者

WebUI 和 hooks 应只发送机器请求；配置文件、启动/停止、恢复由业务引擎处理。写操作持有固定 inode 的原生 flock。停止可以在锁外持久化停止意图、取消正在下载的订阅，但不能 unlink 一个活锁。只读查询不创建状态目录，不自动恢复，不调用人类命令作为降级。

请求包含 `schema: 1`、随机 128 位 `id`、`method`、`expected_revision` 和 `params`。同一 ID、同一请求在记录保留期间返回原结果；不同请求复用 ID 被拒绝。历史保留有界，不承诺永久 exactly-once。

## 配置事务

完整旧值、新值和摘要先持久化，之后发布 prepared journal，再逐文件替换，最后发布 committed 标记。恢复先验证所有证据再回滚；不认识的文件、损坏的摘要或外部改写会保留证据并报错。故障注入覆盖 Store 层每个修改前后，不等同于模拟所有文件系统断电语义。

订阅更新只允许导入节点。路由、监听器、文件路径和认证配置不能来自远程订阅。多来源刷新全部成功后才一起提交缓存；删除来源会删除相应缓存，本地导入独立保留。Clash 转换目前只覆盖代码中列出的协议/传输，不能宣称支持所有订阅格式。

## 生命周期

生成不可变候选配置并由安装的内核校验，然后记录切换意图、停止原进程、启动候选、观察存活，最后提交运行指针。失败恢复旧代。停止优先于旧配置恢复；不确认归属的进程不允许被杀死。超时不对数据面使用 SIGKILL。

**候选适配器仍有阻塞项：** native readiness 目前只证明短时间进程存活；未完成内核/DNS 所有权清理、启动 fork/exec 窗口的完整租约协议、运行日志轮转和代际保留策略。不能把模型测试中的回滚等同于已经证明真实安卓网络恢复。

## 界面

四页分别回答“正在发生什么、节点从哪里来、连接如何配置、失败如何处理”。保存不等于应用。订阅更新失败不清空输入；配置冲突保留草稿；跨页未保存输入不会被另一个保存操作暗中覆盖。没有 NativeBridge 时不伪造正常状态。重要状态不依赖颜色单独表达。

## 尚未迁移的契约

原生产版 `.state/machines/*.state`、MCP、加密备份、Tailscale、热点/Wi-Fi、OEM 网络诊断和完整 hooks/安装器仍在旧实现中。原生产测试不能直接删掉、改为跳过，或用当前较小的宿主机测试集代替。
