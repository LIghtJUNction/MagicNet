# 智能安装与组件自动更新

`magicnet_installer.zip` 仍然叫 MagicNet Installer，不是 core 的别名。Installer 1.1.0 与模块核心使用同一份 `installer/components` 更新引擎，每个新的模块 Release 都附带安装器，与核心包、组件包、完整包一起校验、签名并受发布质量门禁保护。通用 downloader 模板仍单独维护，但不再从另一条并行工作流发布 MagicNet 安装器。

## 智能安装

先通过可信 GitHub HTTPS API 取得最新正式模块和资产 SHA-256，校验组件清单，再比较手机已安装文件与持久缓存。仅下载核心 ZIP 及缺失、损坏或发生变化的组件，复用旧版文件不依赖旧版是否记录过组件清单。相同资产的缓存会重新校验；首次安装必须取得所有必需组件，并不把完整首次下载量变成核心包的大小。

元数据支持 ETag/304；小文件直接下载，不先消耗同样多的流量测速。大文件优先直连，必要时探测镜像，同一批组件复用成功的线路。失败会切换线路，私有 `.part` 文件允许 Range 续传；服务器忽略 Range 时重下而不是错误追加，所有续传最终仍须通过完整 SHA-256。校验失败的完整文件不会进入缓存。

已验证的核心包和组件会在本机重组为临时离线安装输入，再交给当前管理器安装。因此不需要第二次联网，也不会在外层安装器中递归调用 ksud。这个临时组合 ZIP 不是新的官方签名资产；其信任来自已验证的核心 ZIP 和每个组件的 SHA-256。API 元数据无法可靠取得时停止，不能信任镜像自行提供的哈希。

## 定时更新与 WebUI

WebUI「配置 → 组件更新」提供检查、下载并安装、组件复用/下载清单、字节统计、最后/下次检查时间及错误状态。保存设置后会读回确认；后台状态轮询不会覆盖未保存的表单修改。

自动安装默认关闭，检查间隔默认 24 小时，可设置为 1–168 小时，默认仅 Wi-Fi。开启后，设备侧服务执行定时任务，不依赖 WebUI 页面保持打开；开机 service/boot-completed 重复触发不会启动两份调度器。失败按 15 分钟至 4 小时退避重试。休眠期间不持有唤醒锁，唤醒后补一次到期任务，不进行补偿式连续下载。

Wi-Fi 限制使用 root 实际路由的 `wlanN` 接口判定，不把“Wi-Fi 开关已打开”当作 Wi-Fi 正在承载流量。厂商路由无法可靠识别时显示等待 Wi-Fi，可在界面关闭限制后手动检查。设置会在安装前再次读取，关闭自动更新不会继续安装已经下载好的更新。

更新必须按同一个兼容发行版整体安装，不独立追逐某个上游的 latest；组件精度用于减少下载量，而不是混装不同版本的脚本、CLI 与内核。使用 root 管理器暂存到 `modules_update`，确认待安装版本后报告成功，下次用户自行重启生效。不热替换正在运行的内核、不自动重启手机；已有待重启更新时不会再次下载或覆盖。

配置和状态位于 `/data/adb/magicnet-updater`，组件缓存继续使用 `/data/adb/magicnet-components`。它们位于模块目录之外，升级不重置定时设置。关闭模块会让调度器退出。显示的实际传输量统计 HTTP 响应正文（含元数据/测速），不包含协议头等额外开销；计划下载量是完整资产上限，成功续传可能更少。

```sh
cli update status
cli update check
cli update configure 1 24 1
cli update apply
cli update configure 0 24 1
```

测试覆盖可信元数据、304 缓存、只下载变化组件、完整临时包校验、管理器失败/缺少回执、已暂存更新去重、禁用/等待 Wi-Fi、并发锁、配置路径软链接、时间校正、退避、Range 恢复与错误 Range。主机测试、浏览器测试和 Android 交叉编译不等同真机刷入测试。
