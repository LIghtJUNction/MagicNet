# MagicNet v1.5.16

## Tailscale 可随时停用或登出

新增独立的「禁用连接」「恢复连接」和「登出此设备」。禁用保留本机身份，恢复时不必重新登录；登出需要二次确认，移除模块管理的 Tailscale 配置、Auth key 和本机身份。已关闭的核心保持关闭，不会因为修改 Tailscale 而自动启动。

禁用或登出会移除已识别的模块生成路由，并沿用核心的正常停止、清理和启动流程。重复操作、过期页面和订阅同时写入有锁与版本检查。清理或重启失败不会显示成功；身份清理未完成时保持禁用，允许重试，禁止直接恢复旧身份。

自定义路由引用和模块之外的状态目录不会被盲目删除。此时操作会明确失败，需要先处理自定义配置。本机登出不等于撤销云端设备记录；页面保留设备后台入口，供用户在需要时移除云端设备。

## 连接页面

把状态、开关和账号操作集中到连接卡片，区分已连接、暂停、核心关闭、待清理和读取失败。暂停后隐藏重复接入表单；停止登录轮询不再称为取消授权。支持窄屏按钮换行，补齐中文、英文和俄文文案。

## 验证范围

新增 Rust 生命周期与故障注入测试、WebUI 状态测试，以及六种屏幕尺寸的浏览器交互与截图检查。浏览器使用明确的 KernelSU 测试响应，主机测试使用隔离运行时；这些检查不替代真实 root Android 设备上的网络、SELinux、Wi-Fi/移动网络切换或 TUN/eBPF 验收。
