# MagicNet v1.8.0

本版按照当前 Recipkg 配方修正软件，在原有 Rust、Shell、Vue 实现上继续开发。

- 节点与代理组页新增应用、域名和自定义组/出口编辑，草稿先预览，再保存并应用。
- 自定义项通过有归属的增量层生成，保留订阅和系统管理项；订阅更新重新生成时保留自定义项，撤销时保留订阅新增项。发生名称碰撞、组循环或外部冲突时拒绝覆盖。
- 应用选择可读取 Android 主用户的应用名称，支持名称和包名搜索。清单与凭据不进入通用操作输出。
- WebUI 改为矿白、石墨与玉绿配色，保留 14 个页面、原有操作流程、中英俄切换与浅深色主题。
- 包含此前合并的代理组兼容、订阅应用锁、安装与配置恢复修正。

## 安装与更新

Android arm64 root 模块。完整包 `MagicNet-full.zip` 适合离线安装；轻量安装包 `magicnet_installer.zip` 通过已发布的组件清单获取组件。安装前保留自己的配置，更新后按管理器提示重启。下载后可用同一发布页的 `SHA256SUMS` 核对完整性；这不是私钥签名。

默认透明代理仍为 `tun`（`magicnet0`），仅支持显式切换 `tun|ebpf`。eBPF 仍受设备内核能力限制。

## 验证范围

发布前执行本地 Rust、WebUI、浏览器、Android 构建及安装包检查；具体结果记录在配方的验证记录中。浏览器的模拟设备任务和安装夹具不等于真实网络验收。多厂商 Play/GMS、热点双栈、Tailnet 连通性及长期性能场景仍需各自的真实设备证据。
