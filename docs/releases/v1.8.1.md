# MagicNet v1.8.1

本补丁版继续维护现有 Android root / arm64 实现，集中修正订阅处理，并恢复迁移后的正式构建发布入口。

- 多来源订阅聚合保留来自不同来源的同名节点，调整来源身份、节点与代理组引用的处理，减少重名导致的覆盖或聚合失败。
- 统一订阅 URL 的识别和去重：移除不参与请求的片段，保留路径、查询参数和百分号编码的请求含义；前端预览与设备侧保存使用一致规则。
- 调整订阅获取、缓存、配置重建和错误传播，保留节点中的协议字段；修正相关预览、用量显示和自定义分流兼容处理。
- 正式发行继续放在 MagicNet 仓库。构建、质量检查和 Android/KernelSU 模拟器验收使用同一固定源码提交；附件先上传草稿，核对清单及 SHA-256 后再公开。

## 安装与更新

`magicnet_installer.zip`、`MagicNet.zip` 和 `MagicNet-core.zip` 是同一核心包的兼容下载名，模块 ID 均为 MagicNet。`MagicNet-full.zip` 包含离线组件，适合首次安装或网络不便时使用。组件 ZIP 不作为独立模块安装。

更新会保留用户配置和订阅；完成后按管理器提示重启。下载后可用同页的 `SHA256SUMS` 校验完整性，校验和不是独立公钥签名。

默认仍为 `tun` / `magicnet0`，只允许显式选择 `tun|ebpf`。eBPF 可用性取决于设备内核及 cgroup/TC 能力。

## 验证范围与已知限制

正式发行由关联 Actions 的模块、安装迁移、组件、完整质量检查及 Android/KernelSU 模拟器门槛共同放行。模拟器和合成测试不代表 arm64 真机、真实订阅服务、加密服务器互通、多厂商网络或长期运行已经验收。

本版不宣称已确认 Issue #426 的现场根因，也不把工作流通过视为全部多来源订阅场景或独立重建合同均已完成。遇到订阅问题时，请提供脱敏后的来源数量、失败阶段及诊断状态，勿提交订阅 URL 或密钥。
