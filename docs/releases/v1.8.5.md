# MagicNet v1.8.5

默认模板新增五个用户指定目标的拦截规则，版本为 `v1.8.5` / `10613`。

| 精确域名 | 目标端口 |
| --- | --- |
| `flash.sec.miui.com` | 不限 |
| `fraud-detection.engine.miui.com` | 不限 |
| `eps.caict.ac.cn` | 不限 |
| `gateway-papa.cloud.weizhi.com` | 不限 |
| `dm.wo.com.cn` | 仅 `18080`，TCP/UDP |

两个原生 `action: reject` 规则位于既有 DNS、嗅探、ICMP 和 `0.0.0.0` 处理之后、模式与应用及业务分流之前。命中目标的应用流量在 `rule`、`global`、`direct` 模式下均先执行拒绝；域名按完整名称匹配，父域名和子域名沿用原有规则。`dm.wo.com.cn` 的其他端口也沿用原有规则。

DNS 捕获和解析保持现有行为。规则作用于进入 sing-box 且能识别目标域名的流量；使用纯 IP 且缺少域名信息的连接继续按原有规则处理。

## 安装与更新

规则随本版内置模板分发，新安装和正常升级使用该模板，无需额外执行社区模板更新。更新后按模块管理器提示重启。

## 验证要求与范围

发布需通过模板匹配与优先级回归、配置生成和锁定内核校验，以及固定源码的官方模块构建、完整质量与 Android/KernelSU 模拟器门槛。实际结果与来源提交记录于主仓库的 `recipes/magicnet/VERIFICATION.md` 和发行附件 `build-source.json`。

未进行真机安装或真实应用流量验收。
