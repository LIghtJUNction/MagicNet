# MagicNet v1.8.5

本次发行候选为 `v1.8.5` / `10613`，默认模板增加五个指定目标的拦截规则，以及 16 个大陆教育服务域名后缀的默认直连分流。

## 指定目标拦截

| 精确域名 | 目标端口 |
| --- | --- |
| `flash.sec.miui.com` | 不限 |
| `fraud-detection.engine.miui.com` | 不限 |
| `eps.caict.ac.cn` | 不限 |
| `gateway-papa.cloud.weizhi.com` | 不限 |
| `dm.wo.com.cn` | 仅 `18080`，TCP/UDP |

两个原生 `action: reject` 规则位于既有 DNS、嗅探、ICMP 和 `0.0.0.0` 处理之后、模式与应用及业务分流之前。命中目标的应用流量在 `rule`、`global`、`direct` 模式下均先执行拒绝；域名按完整名称匹配，父域名和子域名沿用原有规则。`dm.wo.com.cn` 的其他端口也沿用原有规则。

这些拒绝规则保留既有 DNS 捕获和解析处理，作用于进入 sing-box 且能识别目标域名的流量；使用纯 IP 且缺少域名信息的连接继续按原有规则处理。

## 大陆教育网站默认直连

以下后缀匹配根域名及其子域名，复用现有 `cn-direct` 组，默认选择 `direct`。用户对该组的选择继续保留。

| 范围 | 域名后缀 |
| --- | --- |
| 学校与教育科研域名 | `edu.cn` |
| 教育公共服务 | `moe.gov.cn`、`chsi.com.cn`、`smartedu.cn`、`neea.cn`、`ncss.cn` |
| 慕课与教学平台 | `icourse163.org`、`icourses.cn`、`xuetangx.com`、`yuketang.cn`、`chaoxing.com`、`zhihuishu.com` |
| 教育资讯与学术资源 | `eol.cn`、`cnki.net`、`wanfangdata.com.cn`、`cqvip.com` |

教育规则位于既有模式、LAN、用户与应用分流、广告和 DNS 防护之后，优先于后续国外学术、AI、游戏、开发及媒体分类。DNS 使用相同的 16 个后缀和现有本地加密解析器；前置 DNS 规则继续优先。

范围以此清单为准，其他教育网站与共享 CDN 沿用原有规则。各域名的官方来源见[策略库存](https://github.com/LIghtJUNction/MagicNet/blob/main/recipes/magicnet-routing-policy/POLICY_INVENTORY.md)。

## 安装与更新

规则随本版内置模板分发。正式发行后，新安装和正常升级使用该模板，无需额外执行社区模板更新；更新后按模块管理器提示重启。

## 验证要求与范围

模板层需验证精确拦截、教育后缀与边界负例、规则优先级及 DNS 对应；生成配置须通过锁定内核校验。正式发行还需通过固定源码的官方模块构建、完整质量与 Android/KernelSU 模拟器门槛。实际结果与来源提交记录于主仓库的 `recipes/magicnet/VERIFICATION.md`；发行时由附件 `build-source.json` 记录构建来源。

当前尚未公开发行，未进行真机安装或真实应用流量验收。
