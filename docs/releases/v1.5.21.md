# MagicNet v1.5.21

[下载增量安装器](https://github.com/LIghtJUNction/MagicNet/releases/download/v1.5.21/magicnet_installer.zip)，或从[发布页](https://github.com/LIghtJUNction/MagicNet/releases/tag/v1.5.21)下载离线完整包。

本版在 WebUI 内置模块更新，改进节点选择界面，修正停服、更新恢复和诊断安全问题。

- **WebUI 一键更新模块。** 在概览中检查正式版本并直接下载、校验和安装。更新任务在设备后台运行，关闭或刷新面板后可继续查看状态；安装完成提示手动重启，重启前仍显示实际运行的旧版本。只接受本仓库的正式发布包，遇到已有暂存安装或无法确认的中断状态时保留证据并阻止重复安装。
- **完整节点列表可达。** 分组和节点可逐批展开，搜索覆盖完整列表，当前选择优先显示。长名称完整换行，搜索无匹配、空列表和读取失败分别给出明确反馈；搜索框支持清除及键盘操作，引导弹窗适应短视口和软键盘。
- **停服反馈更准确。** 保留 TERM/KILL 发送失败和进程检查失败，进程信息不完整时报告未知状态，不再误报停止成功。等待期间重新核对进程身份，避免把旧进程的强制停止期限套到新进程上；确认停止后继续尝试清理各项资源，并保留清理错误。
- **后台进程诊断保持真实。** 主进程与监督进程的身份或 PID 文件无法可靠读取时报告未知，不当作已停止；未能确认退出时保留相关记录并向停服调用方返回失败。
- **恢复前先检查完整备份。** 更新恢复先核对需要恢复的配置与来源备份，再写入运行配置；暂存文件通过校验并设置私有权限后才替换目标，减少不完整记录导致的配置损坏。
- **多用户与共享应用识别更完整。** 保留多用户包列表中的全部应用身份，拒绝格式错误或越界的 UID；系统策略回读已解除限制时，清除过期的拒绝状态。
- **网络与 DNS 检查更稳妥。** 校验 TUN 地址预留的 DNS 地址仍在同一网段，并排除 IPv4 广播地址；DNS 规则检查同时核对端口与动作，减少把普通 HTTP 跳转误判成 DNS 风险的情况。无归属证据时不直接删除接口。
- **保护私有配置与恢复副本。** MCP 通用文件接口限制访问私有配置、恢复记录、缓存和暂存副本，包括别名路径。Android 下载只使用已打包或系统可信的 curl，缺少可用程序时明确失败。
- **保留合法诊断参数。** 有界校验继续允许合法的 BPF 过滤表达式，限制参数数量和长度，避免安全检查阻断正常诊断。
- **安装验收更严格。** 无效配置必须被校验程序正常拒绝；进程崩溃不能算作校验成功。启动测试要求真实初始化的框架辅助脚本，并核对实际配置转换结果。

从本版开始，后续更新可直接使用 WebUI 概览中的更新按钮；首次安装推荐使用 `magicnet_installer.zip`，需要离线安装时使用 `MagicNet-full.zip`。`MagicNet-component-*.zip` 是组件载荷，不是独立可安装模块。安装后重启，在 WebUI 检查运行状态。

评论中反馈的停止后断网与更新失败，本版分别改进了停止错误传播、资源清理和配置恢复保护。原始设备及来源仍需各自复核，这些改动不能保证所有同类症状都来自相同原因。
