# MagicNet v1.6.0

[下载增量安装器](https://github.com/LIghtJUNction/MagicNet/releases/download/v1.6.0/magicnet_installer.zip)，或从[发布页](https://github.com/LIghtJUNction/MagicNet/releases/tag/v1.6.0)下载离线完整包。

本版重做 WebUI 视觉与导航，新增实时流量星座和快速跳转，并为热点状态提供结构化机器接口。透明代理行为、配置格式和数据面语义均未改变。

- **全新 Constellation 界面。** 配色直接取自 MagicNet Logo：浅色是奶油纸面、墨线与陶土橙，深色是带稀疏星点的暖色夜空。卡片、展开项、标签页、底部导航和桌面侧栏统一重绘；标题使用系统衬线字体，不下载任何外部字体。高对比度、强制颜色和减少动效模式继续受支持，触控目标保持至少 48px。
- **概览实时流量星座。** 概览把流量路径画成四颗星：设备 → 数据面（TUN `magicnet0` 或 eBPF）→ sing-box → 出口。每颗星只由机器接口报告的事实点亮，两端都已证实时连线才会流动；未知状态显示为静态虚线，不会画成已接管。出口点亮只表示 sing-box 已就绪并按规则分流，实际联网仍以诊断结果为准。
- **快速跳转。** 按 `Ctrl/⌘ + K` 或 `/`，也可点顶部搜索按钮，即可搜索全部页面和面板操作（刷新、切换外观、新手引导、反馈、GitHub）。支持中文原文与当前语言译文匹配，全程可用键盘操作；快速跳转不会执行任何修改设备的命令。
- **重新设计的导航。** 手机底部改为悬浮胶囊导航；分区标签改为分段轨道。桌面侧栏为每个页面配图标，底部常驻实时状态卡，显示服务状态、透明模式和内核内存，点击即可回到概览。
- **新增 `hotspot.status` 机器接口。** `cli --json hotspot status` 分层报告热点代理意图（`configured`）与对账后的转发状态（`effective.route_state`：`disabled`、`waiting`、`pending`、`active`、`shared`、`unknown`），与 `.state/machines/hotspot.state` 使用同一对账逻辑。接口不返回接口名、网段或客户端身份。WebUI 改用该接口，不再解析人类可读文本；MCP 新增只读工具 `magicnet_hotspot_status`，`capabilities` 同步公布。
- **数据面就绪证据。** WebUI 现在单独读取 `service.status` 中的 `transparent.dataplane_ready`；sing-box 停止时不会沿用过期的“已就绪”。
- **配置编辑保护。** 重新加载和导入 JSON 前确认未保存的修改，刷新页面时提醒；同步模板也会说明草稿覆盖影响。切换页面保留草稿，不把私密配置写入浏览器存储。
- **更清楚的操作菜单。** 启动与停止独立显示；终端支持数字选择，管理器支持音量键。停止服务和更新订阅需要确认，默认取消；自动化模式不等待按键、不执行写操作。命令失败状态不会被菜单或状态刷新吞掉。
- **安装前校验。** 首次安装和升级均使用随包工具检查模板，包括没有旧节点的升级；检查失败时保留原配置与备份，诊断内容不泄露节点信息。
- **设备端引导页与告别页同步新配色。**

首次安装推荐使用 `magicnet_installer.zip`，需要离线安装时使用 `MagicNet-full.zip`。`MagicNet-component-*.zip` 是组件载荷，不是独立可安装模块。已安装 v1.5.21 及以上版本时，可直接在 WebUI 概览中更新；安装后重启设备生效。
