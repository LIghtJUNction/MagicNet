# MagicNet v1.5.20

[下载增量安装器](https://github.com/LIghtJUNction/MagicNet/releases/download/v1.5.20/magicnet_installer.zip)，或从[发布页](https://github.com/LIghtJUNction/MagicNet/releases/tag/v1.5.20)下载离线完整包。

修复 Oplus 设备上“Play 商店联网修复”无法解除限制的问题。部分固件允许读取联网策略，却拒绝 root 调用写接口；v1.5.19 因而可能保存了恢复记录，但实际解除失败。

现在由 root 启动的独立桥接进程在连接系统接口前切换到 Android 系统身份，再执行已确认的解除或回滚。应用身份、共享应用名单、原策略校验、事务记录及策略回读继续生效。权限拒绝返回明确的 `permission_denied`，不输出原始系统错误。

本轮已在 Oplus Android 16 真机部署修复，验证 Play 和共享 GMS/GSF 身份的回滚、解除及复查；用户确认 Play 搜索和下载均正常。Java 桥接、Rust 恢复事务和升级保留共 33 项专项测试，以及完整本地提交检查通过。

同时修正新 Rust 工具链下的 MCP 连接配额编译兼容性，保留并发上限，补充并发争用和计数边界测试。

更新后进入 **工具 → Play 商店联网修复**，检查并确认需要解除的限制。此前失败留下的未完成记录需先回滚，再重新解除。安装不会自动取消联网限制；修复也不阻止厂商未来重新施加策略。其他厂商的兼容性仍需各自验证。

详见[应用联网策略恢复说明](../network-access-recovery.md)，关联 [#329](https://github.com/LIghtJUNction/MagicNet/issues/329)。
