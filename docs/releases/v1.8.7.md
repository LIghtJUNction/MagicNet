# MagicNet v1.8.7

## 证书策略默认关闭

- 系统证书禁用功能默认关闭，未配置 enabled 时按 false 处理。
- 开机 apply 在未启用或已关闭时直接返回，保持系统证书状态。
- 需要禁用时可显式运行 certificate-policy disable，preview 与 restore 继续可用。
- 保留已经明确设置的用户意图。曾手动禁用的证书需要显式恢复。

本地真实 X.509 回归覆盖默认关闭、开机无操作、显式禁用、恢复、幂等与归属冲突恢复。

## 模拟器验收修复

- 修复 Wi-Fi 上联故障注入后只恢复链路、未恢复 Android Wi-Fi 框架关联的问题。
- 前台和独立延迟恢复 guard 使用相同的系统 Wi-Fi 恢复流程，并有界等待接口重建。
- 保留恢复后真实默认路由、TUN、就绪和同应用 UID TCP 流量验收，报告门禁核对恢复方法。
