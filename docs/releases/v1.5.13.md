# MagicNet v1.5.13

日期：2026-09-22。版本代码：1789322931004。

## 本次修复

- 更新 sing-box 配置：普通 TCP/UDP 53 DNS 提前接管，保留协议嗅探回退；已知海外域名先于国家 IP 兜底匹配，国内域名和明确服务例外仍保留优先级。
- 微信 DNS 使用仅域名规则，避免把混合域名/IP 规则直接用于 DNS；补齐对应规则发布包、manifest SHA-256 和模板下载校验值。
- 配置仓库设置、安装器、Rust CLI 和 WebUI 使用一致的默认模板版本，路由诊断同步识别新的域名优先顺序。
- 路由优化器保留有状态 DNS 操作和匹配边界，不因去重或重排破坏 `evaluate`、`resolve`、`sniff` 等操作顺序。
- 停服时为 Rust CLI/WebUI 和 Shell 路径提供约 10 秒的有界正常退出窗口，核心退出即返回；失败启动的回收使用同一逻辑。未知进程状态和未退出的进程仍报告失败，避免提前强杀打断核心清理。
- 包含此前合入的 APatch/Magisk 开机 `ip` 工具选择修复（#338 / #334）。

相关变更：MagicSingBox #19；MagicNet #339、#340、#341。

## 安装与验收范围

联网安装使用 Release 中的 `magicnet_installer.zip`；离线安装使用 `MagicNet-full.zip`。不要把无订阅节点的仓库模板直接覆盖设备运行配置。升级前应保留现有配置备份。

发布流程在最终提交上重新执行完整质量门禁，校验安装包、组件及签名后才公开 Release；PR 测试通过不替代发布提交的验证。

已完成代码及宿主机回归，不代表 Android 真机网络验收。#336、#337 仍保留用于验证停止后的应用直连、系统 DNS、Wi-Fi/蜂窝及异常退出恢复；本版本不宣称修复核心真正卡死后的所有内核残留。不会清空系统防火墙、按通用名称删除其他代理实例的规则或放宽 SELinux。
