# MagicNet v1.8.2

本补丁版维护现有 Android root / arm64 实现，整合订阅更新、MCP 隐私边界与手机端可用性修复。

- 为最多五个来源的订阅更新设置独立、有界的批处理预算，避免沿用普通命令 180 秒期限而过早终止；各来源获取、转换及退出后的回滚仍有限时，控制进程退出后的清理预算不随批处理放大。
- WebUI 正确追踪私密订阅应用任务，保留进行中与失败反馈；增加跨来源同名 WebSocket 节点与退出恢复回归。
- MCP 通用文件接口拒绝热点恢复记录、应用 UID/包名清单、selector 选择和接口名等私密文件，包括 staging/backup 名称；通用 CLI 拒绝人类热点和应用清单输出。继续使用具名工具及脱敏 JSON 状态，不削弱 canonical 状态接口。
- 改善窄屏导航、编辑器、终端和应用列表使用体验，并避免空终端按钮被手机底栏遮挡。
- 同步固定的 sing-box 1.15.0-alpha.13 内核与配置来源，保留 tun/ebpf、事务回滚和最小披露合同。

## 安装与更新

`magicnet_installer.zip`、`MagicNet.zip` 和 `MagicNet-core.zip` 是字节一致的核心包兼容下载名。`MagicNet-full.zip` 包含离线组件；组件 ZIP 不能单独作为模块安装。更新后按管理器提示重启，保留用户配置与订阅。

默认仍为 `tun` / `magicnet0`，只允许显式 `tun|ebpf`；eBPF 依赖设备内核的 cgroup/TC 能力。`SHA256SUMS` 用于完整性校验，不是独立公钥签名。
