# MagicNet v1.6.1

本版本主要完善 CLI 与 WebUI 的资源边界，以及热点策略切换失败时的恢复行为。

## 修复与改进

- WebUI 原生命令输出同时限制累计大小与事件数量。超限后丢弃输出并明确报错，仍等待原生命令结束才释放执行队列，避免部分机器 JSON 被误当成成功结果。
- 节点延迟查询、Tailscale 本地 API 等 curl 调用复用有界子进程执行器，统一处理超时、输出截断和进程组回收。私有 curl 配置通过有大小上限的非阻塞 stdin 传入，不进入命令行参数。
- Wi-Fi 策略的读取、编辑与后台应用共用 64 KiB 边界。损坏、超限或非 UTF-8 输入明确失败，不再退化为空列表，也不会在失败时改写既有配置或运行模式。
- 热点开关与通用 hotspot selector 写入共用生命周期锁。持久化失败时不修改运行策略；后续步骤失败时恢复原有选择、其他 selector 及相关资源，不再一律回退直连。
- 热点补偿分别恢复配置意图与已观测的运行选择；API 失败不会跳过独立的 offload 和路由清理，回滚未完成时明确返回错误。
- selector 配置的严格读取、写入和旧配置迁移清理增加文件类型、符号链接及 4 MiB 边界检查，避免 FIFO 阻塞或无界读取。
- 补充命令资源、执行队列、Wi-Fi 输入与热点失败路径回归，并改善部分宿主测试的时序稳定性。

## 兼容与发布说明

- 默认透明代理模式仍为 `tun`，继续显式支持 `tun|ebpf`，不新增自动模式。
- 本次保持已锁定的 sing-box 核心及默认配置子模块版本，不包含本地子模块的 DNS/路由调整。
- 正式资产仍由既有签名、完整性检查和 Android 验收门禁控制；上述回归不代表已经测量或消除了设备端 sing-box 内存泄漏。
