# MagicNet v1.5.18（待发布）

截至 2026-10-01，本文件是发布候选说明，不代表 Android 验收通过或安装包已发布。当前公开稳定版仍为 v1.5.14。

修复独立配置在启动时被热点策略改成无效配置的问题。只有 `direct` 或使用自定义出口标签的配置，现在会使用实际存在的出口；标准订阅配置继续保留热点的 `direct` / `proxy` 选择。没有有效出口时拒绝写入，并保留原配置。

修复 sing-box 1.14 对最终启动配置的拒绝：缺少默认域名解析器时从所选 DNS 解析器补齐，保留已有显式设置。独立配置在默认 DNS 策略下保留自己的 DNS 服务器、规则和最终解析器；明确选择 Cloudflare 策略时仍按用户选择应用。独立配置省略 DNS、使用空服务器列表或显式关闭缓存时，不再对空值执行 `map`，也不凭空添加解析器和 DNS 缓存；格式错误仍拒绝写入并保留原文件。

修复没有系统 curl 的 Android 设备上 CLI / WebUI 无法访问本地核心 API 的问题。增加仅允许回环地址的内置 HTTP 传输，支持状态查询、模式和节点切换、连接清理；限制请求时间及响应大小，拒绝重定向和不完整响应。健康检查同时验证 HTTP 成功状态和有效版本字段，避免误报。

启动配置和节点判断改用打包的 jq，避免在包含中文节点名称的长 JSON 行上执行 BusyBox 正则。应用列表和通用列表改为按字节判断空白；Android 用户编号从 `UserInfo` 前缀提取后再校验数字，避免 awk/sed 的 UTF-8 字符集崩溃。订阅字段的 JSON 转义同样改为字节操作，保留中文并正确处理引号、反斜杠和控制字符。保留主线对 UID 查询失败的严格处理，不把解析失败当作空名单或成功。

签名发布新增同一主线提交的 Android 验收检查。失败、取消、跳过、缺少必要任务或等待超时均阻止发布，不能用旧提交或仅 PR 的通过结果替代。

修复已定位的发布构建后宿主机检查问题。Linux 路由和订阅测试使用独立的宿主机环境，避免执行安装包中的 Android ARM64 工具。Android 验收报告增加核心配置检查、持久化 KAM 日志、本地 API 诊断和规范化启动状态。

本版还包含 v1.5.14 之后主线累计的本地订阅导入、DNS/TUN 参数、停服宽限期和网络规则清理、热点 IPv6 旁路，以及 Tailscale 禁用、恢复和登出相关修复。

自动验收使用 Android 15、KernelSU v3.2.0 和 x86_64 模拟器，检查安装、启动、普通应用 UID 的 TUN 控制、无效配置回滚、启停、升级保留配置、禁用、启用和卸载。该环境不能代替 ARM64/OEM 真机、Google Play/GMS 和 eBPF/IPv6 数据面验证。

## 发布前检查

[Android 验收运行 36726242388](https://github.com/LIghtJUNction/MagicNet/actions/runs/36726242388) 记录了 BusyBox awk 和系统 sed 的 UTF-8 正则崩溃。相同 SHA-256 的 KernelSU 二进制在宿主机可复现；本次修复后的实际应用列表、用户编号、通用列表及长 JSON 检查已通过该二进制的回归。预检检查改为生产路径实际使用的字节解析操作及 ASCII 元数据操作，仍严格检查输出、退出码、超时和身份。此修复不宣称修好了系统 Bionic 库，也不代表完整 Android 生命周期已通过。

DNS 空配置回归在旧实现失败、候选实现通过；宿主机脚本检查不等于 Android 验收。发布仍要求同一最终提交上的完整 CI、Android 安装/启停/升级/禁用/卸载和 TUN 正向/拒绝/恢复检查通过，再验证签名及安装包。不得跳过 BusyBox 预检、用旧提交结果代替新提交，或把未执行的阶段算成成功。

候选说明不提供尚未生成的下载链接。完成上述检查并发布后，再补充最终验证结果和安装包入口。
