# MagicNet v1.6.2

## 版本码迁移 / Version code migration

本版本将 `versionCode` 从历史毫秒级数值迁移为 `10602`，以符合 KernelSU Modules 的 32 位正整数限制（最大 `2147483647`）。后续版本码继续递增。

**v1.6.1 及更早的旧版本用户需要手动安装一次。** 旧版本码大于新版本码，管理器的自动更新比较无法完成这次迁移。先备份 MagicNet 配置，从本项目 Release 下载 `MagicNet-full.zip`，在 root 管理器中直接手动安装并按提示重启，不要先卸载模块。迁移完成后确认版本为 `v1.6.2`、版本码为 `10602`；后续更新恢复递增顺序。

Existing users must manually install this release once because the legacy version code is larger than the new code. Back up your configuration, download `MagicNet-full.zip` from this project's Release, install it directly through your root manager, and reboot as prompted. Do not uninstall first. Confirm `v1.6.2` / `10602` after installation. Future version codes will increase normally.

## 发布与收录

- 添加 KernelSU Modules 的 `module.yaml`，目录下载入口指定完整离线包 `MagicNet-full.zip`。
- 开启 GitHub Release immutability；新发布的附件与标签发布后不能替换。
- 发布准备脚本提前拒绝超范围版本码，递增达到上限时在写文件前失败。
- KernelSU 目录是否收录，以开发者门户的维护者审核结果为准。
