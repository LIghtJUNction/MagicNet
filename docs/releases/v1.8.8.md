# MagicNet v1.8.8

本版更新默认配置和规则资产，修复托管分流的插入顺序，并整合此前已合入的可信本地订阅与简约 WebUI。完整验收记录见 [VERIFICATION.md](../../recipes/magicnet/VERIFICATION.md)。

## 分流顺序

应用策略、自定义域名和广告规则按固定顺序插入。DNS 捕获、模式、拒绝目标、LAN 和 Tailnet 保护继续优先；`sniff`、`resolve`、`route-options` 先准备域名、解析地址和连接参数，再执行新增的终止路由。

普通业务规则即使显式写了 `action: route`，也不会被提前到应用选择之前。已有规则保持原始相对顺序，重复应用结果一致。自定义配置中交错在后置保护之前的业务规则保留已有优先级；配置生成不重新排列用户数组。缺少必要嗅探或保存失败时保留原配置。

## 默认 DNS 与规则资产

`.local` 名称、IPv4 `169.254/16` 和 IPv6 `fe80::/10` 的反向查询使用原生 mDNS，先于 Direct/Global 的公共 DNS 规则。查询在本地链路完成；没有可用接口或设备响应时失败，不转交公共解析器。`home.arpa` 和 `.lan` 仍沿用既有策略，本次未增加家庭 DNS 发现。

未知公网域名继续通过代理 DNS，节点域名保留独立引导解析。默认模板固定至 [MagicSingBox da3d375](https://github.com/LIghtJUNction/MagicSingBox/commit/da3d375d024e0982265bc67c48a87de7bb4f9424)，规则固定至 [rules-20261115-585094101194f32e](https://github.com/LIghtJUNction/MagicNetRules/releases/tag/rules-20261115-585094101194f32e)，构建核验归档和每个规则文件的摘要。升级只迁移已知官方提交与摘要的精确组合，自定义仓库、版本和摘要保留。

## 可信本地订阅

整合 [源码 PR #8](https://github.com/LIghtJUNction/magicnet-android/pull/8) 的 NAS/Tailnet 订阅授权。默认远程来源仍限公网 HTTPS；本地 HTTP/HTTPS 来源须先授权精确 origin 和本地 CIDR。每次下载、重试和重定向均检查全部解析地址并固定实际目标，HTTPS 继续验证证书。

可选代理仅接受带显式端口的字面 loopback SOCKS5，不自动启用 Tailscale 或代理。WebUI 接受 HTTP 输入只代表语法有效，权限由后端检查；失败保留草稿和旧配置。升级保留设备上的授权表与订阅历史，新装默认无授权，发布包不携带构建环境的授权表。操作与限制见[可信订阅说明](https://github.com/LIghtJUNction/magicnet-android/blob/45154757c104b56c8a5dad24c8386fddf4d94c89/docs/trusted-subscriptions.md)。

## 界面

沿用中性色、留白与连续分区，流量路径静态展示真实状态；移除重复装饰和模型署名。修复 320px 俄语状态标签越界，保留三语、键盘操作、危险确认和草稿行为。

## 安装与验证范围

安装入口为本仓库正式 Release 的模块 ZIP。`MagicNet-core.zip`、`MagicNet.zip`、`magicnet_installer.zip` 保持同一在线安装入口，`MagicNet-full.zip` 提供离线完整组件。具体资产身份以该发行的 `SHA256SUMS` 与 `build-source.json` 为准；升级完成后的重启由用户决定。

发布流程核验固定源码、完整质量检查、Android/KernelSU 模拟器生命周期、网络恢复证据和最终资产。配置与模拟器测试不能代替物理手机、实际 NAS 或 mDNS 组播网络验收；相关设备验证仍开放。
