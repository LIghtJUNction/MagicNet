# MagicNet v1.9.0

本版精简日常导航和概览页，并修复代理核心意外退出后网络拦截规则未被及时清理的问题。

## 日常操作

桌面侧栏和手机底栏直接提供「概览、节点、订阅、应用」。其余页面通过「更多功能」进入，原有深链接和快速跳转继续可用。切换页面保留未提交的表单内容。

概览首先显示代理状态、启动或停止按钮，以及「检查网络」入口。节点和订阅可以直接打开；运行证据、内存、TUN/eBPF、热点与 Wi-Fi 设置按需展开。移除重复的分区导航和概览装饰性流量图，流量路径说明仍可在原页面查看；真实状态以运行详情和诊断结果为准。

保留浅色、深色主题与中、英、俄三种语言。运行状态未知时仍要求先读取状态，未就绪和联网异常继续显示实际结果；精简布局不改变写操作确认和错误处理。

## 核心退出后的网络恢复

以前，代理核心意外退出后，监控只记录暂停，可能留下仍指向本地 DNS 端口的转发规则。新版在确认核心已经停止后，复用正常停止流程清理 MagicNet 自有的 DNS、热点和路由资源。

清理与启停、配置操作共用互斥锁。核心重新启动、状态未知或锁忙时暂缓；失败保留证据并在后续本地检查重试。此过程保持用户的配置和节点选择，不自动重启核心，也不发送新的公网探测。界面继续区分代理运行状态与互联网连通性。

## 安装与验收范围

在线安装使用 `MagicNet-core.zip`、`MagicNet.zip` 或 `magicnet_installer.zip`；完整离线安装使用 `MagicNet-full.zip`。下载后可用本发行的 `SHA256SUMS` 核对文件。

正式发布沿用固定源码构建、完整质量检查、Android/KernelSU 模拟器生命周期和网络恢复验证、最终安装包核验。模拟器、宿主回归与物理手机的结果分别记录。本轮未在用户的物理手机和实际订阅上复现原始断网现场。
