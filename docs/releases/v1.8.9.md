# MagicNet v1.8.9

本版修复 Android 构建输入下载和 GitHub 草稿发行定位，更新 sing-box fork、规则、构建工具与兼容依赖，并保留现有透明代理及文本诊断行为。Android versionCode 为 10617。

## 发布与构建修复

发布器直接使用创建草稿响应中的数字 release ID，避免创建成功后因列表尚未更新而中断。原有源码、run、artifact、目标版本和附件摘要检查继续执行；全部必需门禁通过后公开发行。

zlib 固定下载源改为官方 GitHub Release 资产。缓存命中先校验摘要，损坏缓存重新下载，校验成功才替换；HTTP 200 的错误页面仍会被拒绝。curl、OpenSSL、zlib 和 Mozilla CA 共用构建锁，Android 验收从同一锁读取内嵌证书包的摘要、字节数和证书数。

## 兼容与代码精简

Android 可执行文件检查读取 ELF 结构，识别系统 Android 解释器与无外部动态依赖的静态可执行文件。新版 eCapture 的 static PIE 格式纳入验证，同时拒绝普通共享库、错误架构和 GNU 动态加载器。

TLS/GoTLS 文本诊断显式使用 eCapture 的 hook 来源，避免上游新默认值改变现有捕获方式。原有时长、输出上限和 PID/UID 过滤保留。规则安装只比较一次文件内容，未变的规则不重写，损坏的目标仍会修复。

Rust 兼容依赖和 npm/Bun 双锁同步更新。TypeScript 保持 5.9 系列；机器接口、持久化字段和默认 TUN 模式保持既有合同。

## 安装与验证

正式安装入口为本发行的模块 ZIP。MagicNet-core.zip、MagicNet.zip、magicnet_installer.zip 提供同一在线安装入口；MagicNet-full.zip 提供完整离线组件。资产身份和校验值以本发行的 build-source.json、components.json 和 SHA256SUMS 为准。

发布流程对固定源码执行完整质量检查、模块构建、Android/KernelSU 模拟器生命周期、网络恢复证据及最终资产验证。模拟器与物理 ARM64 手机、实际订阅和实际网络的验证范围分别记录；本轮未对用户手机执行升级或重新配置网络。
