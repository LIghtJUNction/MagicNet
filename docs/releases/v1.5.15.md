# MagicNet v1.5.15

## 订阅导入与来源管理

修复多来源订阅转换提前失败的问题。每个来源单独交给模块锁定版本的转换器解析，再合并节点；混合 Clash/Mihomo YAML、分享链接、base64 和 sing-box JSON 时，不再只读取分享链接而丢掉其他来源。

修复 YAML 的 ALPN、WebSocket 等嵌套列表被误认为新节点的问题，识别带 BOM、CRLF、注释和行内列表的 Clash 内容。转换失败且原生回退不能完整覆盖来源时，保留原配置并报告失败，不静默启用缺少来源或传输参数的配置。此版本不声称支持所有 Mihomo 专有字段或远程 proxy-providers。

订阅页直接打开时会读取设备来源状态；更新中的旧请求不能覆盖较新的读取结果。新增确认后的“移除所有来源”，同时清除 URL 和本地文件来源，移除后不再显示旧来源用量卡片。对应的人类 CLI 命令为 `cli sub clear`，重复执行安全，与订阅写入和生命周期操作串行化。

**移除来源不是停止核心。** 当前已验证配置保持不变，不会因清空输入框而突然断开正在使用的网络。需要重新启用订阅时，重新添加 URL 或导入文件。

## 启停恢复

修正 TUN 清理对同优先级规则的判断：sing-tun 合法创建的多条规则，只在全部属于本次已记录的运行代际时才允许清理。记录并回收已确认属于模块的跳转、终止规则；发现第三方同优先级规则、进程状态未知或所有权证据不足时停止清理，不批量删除系统路由。

新增连续启动/停止、重复停止、同优先级 netlink 删除语义及第三方规则保护回归。这个修复针对已复现的清理缺陷，不等于已经验证所有 Android 内核和厂商系统的断网原因。

## WebUI

重新整理订阅来源编辑区，明确粘贴、导入、保存和删除的关系，并补充中、英、俄文案。Tailscale 默认突出网页登录，Auth key 接入单独展开，保留验证错误、未保存配置保护和密钥脱敏。工具页的七组高级操作按项展开，表单草稿不因折叠丢失。统一各页面标题、间距及窄屏按钮换行。

加入 13 个页面的深浅主题截图检查，覆盖 320、360、390、430 像素宽度、横屏和桌面；订阅删除、失败保留、文件导入和 Tailscale 登录流程有浏览器交互回归。CI 的 `webui-page-evidence` 保存截图与失败诊断。

## 验证范围

测试包括真实锁定版本的 Proxylink 转换器、Shell 路由/订阅故障注入、Rust 控制面测试，以及真实浏览器渲染。浏览器的 KernelSU 接口使用明确的测试响应；主机规则测试使用隔离模型。它们不能替代实际 root Android 设备的 DNS、应用流量、Wi-Fi/移动网络切换及 TUN/eBPF 验收。Google Play / 多 OEM 的既有验收问题不因本版本而关闭。
