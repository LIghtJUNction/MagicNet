# v1.5.6 发布说明（候选）

版本：`v1.5.6`，`versionCode=1789322930997`。这是发布准备，尚未发布正式版。

## 本次修改

- 双栈模式补齐 IPv6 本地 DNS 监听；切回仅 IPv4 时移除对应的旧监听和重定向。已有正确的 DNS 规则不重复写入。
- 启动前记录规则基线，停止时仅清理能够确认属于 MagicNet 的规则。无法确认归属、读取失败或清理失败时保留恢复记录，不把网络状态标成已恢复。
- 修正启动失败后的清理顺序、热点硬件加速恢复及并发保护。已退出但尚未回收的守护进程不再阻塞停止或重配置；读取不到仍存活进程的信息时继续报告未知状态。
- 保留 Tailscale 配置和页面状态修复，避免授权过程中不必要的重复重启和离开页面后的过期更新。
- 反馈优先保留 Play/GMS 的实际分流记录，隐藏凭据和订阅节点名称，并增加只读进程内存明细。内存明细是诊断信息，不代表已经降低真机内存占用。

## 验证范围

候选分支同时保留 #307 的 DNS/进程修复和 #313 的规则归属、失败回滚修改。模拟内核测试覆盖“删除自身规则”和“保留其他程序规则”两个方向，不能用永远成功的模拟命令代替真实状态。

发布前应核对最终提交的代码质量、WebUI、网络回归、模块构建、安装器、签名及完整发布质量门禁。旧分支的绿色检查不能代替合并后候选版本的结果。

## 尚未完成的设备验收

Google Play 的搜索、图片、下载和 GMS 在受影响手机上仍需验收（#253、#304、#305）。模块启停后网络恢复和 Wi-Fi/移动网络切换也需在相同设备条件下确认。主机测试、DNS 回应或 HTTP 成功不等于应用恢复。

没有加入强制 Google 直连、全局屏蔽 UDP/443、自动替换订阅节点、全表路由清空或新的默认代理模式。

## 发布与回退

版本 PR #308 保持草稿；本次不创建正式 tag、不发布 Release、不更新线上下载入口。现有 `.github/release-request` 是后续显式批准发布时使用的请求：把该版本 PR 合并到 `main` 会触发正式发布流程，不能把合并视为单纯的准备操作。

正式发布前保留上一版已验证的安装包和设备配置备份。失败回退仍应通过现有模块生命周期完成，保留无法确认的恢复记录，不通过删除状态文件或强制清空系统规则制造“恢复成功”。
